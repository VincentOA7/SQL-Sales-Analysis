# 📊 SQL Sales Analysis

### Turning Sales Data into Meaningful Business Insights

---

## 📌 Project Overview

This project explores sales data using **SQL Server** to uncover meaningful insights into sales performance, customer behavior, and product trends.

The goal of the analysis is to transform raw data into actionable insights that can support decision-making in business.

---

## 🎯 Objectives

* Analyze sales trends
* Identify top-performing products and customers
* Understand sales performance
* Find patterns and useful business insights
* Reports for data visualization in Tableau or Power BI

---

## 🛠️ Tools Used

* **SQL Server**

---

## 🔍 Analysis

1. **Change Over Time Analysis**
2. **Cumulative Analysis**
3. **Performance Analysis**
4. **Part-to-Whole Analysis**
5. **Data Segmentation**
6. **Customer & Product Report**

---

## 💡 Key Insights

* 📈 **Sales Trends:** Yearly and monthly sales performance
* 🏆 **Product Performance:** Top-performing product categories
* 📊 **YoY Analysis:** Year-over-year sales changes
* 👥 **Customer Performance:** Top-performing customers
